## 1. 先に結論
印刷会社向け PoC(画面名「つもる」)は、**過去の見積から似た案件を引いて、見積の叩き台を出す道具**。見積書を発行するシステムではない(`docs/SPEC.md:130` で「見積書 PDF の発行は対象外」と書かれている)。

そのため、メンターの指摘(D77-6)で期待されていた「見積・明細・台帳・帳票」のうち、次のものは**入っていない**。
- 明細、見積の版、消費税、帳票(印刷・PDF・CSV)
- 監査ログ、RLS、論理削除、認証

流用できるのは主に次の3つ。
- 見た目と操作の作法(CSS の変数、ダイアログ、フォーム)
- サーバー側の処理の形
- 「似た過去の見積を引いて叩き台にする」という考え方

最後の考え方は、現場台帳の「同じ物件の前回の見積を横に出して写す」(SPEC-v2 §5.4)と同じ筋で、段階3 で使う。

| 項目 | 印刷 PoC | 現場台帳 v2 で要るもの |
|---|---|---|
| 技術 | Next.js 16、Drizzle、Neon(Postgres)、認証なし | Next.js 15、Supabase(認証・RLS)、zod |
| 見積 | 1行=1見積(仕様と金額が同じ行)。版なし、上書き | 見積の頭と明細を分け、版を持つ |
| 税・端数 | 計算なし(「税抜・概算」と表示)。`Math.round` で四捨五入 | 税率を持ち、合計に対して1回だけ計算する |
| 採番 | insert のあと `E-{id}` を update で付ける | 1回の処理で振る(年度の連番) |
| 監査・削除 | 物理削除、履歴なし | 監査ログ、論理削除、DELETE の権限なし |
